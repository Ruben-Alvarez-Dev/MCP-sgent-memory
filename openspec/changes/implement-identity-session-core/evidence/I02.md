## Scope

Implemented the pure identity-domain model only. The model establishes immutable
UUIDv7 identifiers, explicit principal kinds, canonical memory scopes, bounded UTC
validity, versioned credentials and policy, normalized capabilities, and typed
construction or activity failures.

No store, runtime handler, model invocation, production data, deployment, or
external service changed.
