# Current specifications

This directory contains verified deployed behavior only.

The normalized identity, session, isolation, storage, promotion, and shared-compute
contracts are currently proposed under
`openspec/changes/establish-jart-memory-foundation/specs/`. They must not be copied
here or described as current until their implementation, real-component tests,
security review, migration evidence, and acceptance gates are complete.

Legacy behavior remains represented by the source and its characterization tests;
it is not silently normalized into a target specification.
